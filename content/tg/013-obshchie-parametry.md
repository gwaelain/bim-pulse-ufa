<b>Спецификация не собирается по всем разделам — почти всегда из-за этого</b>

Параметр проекта живёт внутри одного файла. Общий параметр — в отдельном txt, одинаковом для всех.

Пока каждый отдел заводит «свой» параметр «Марка изделия», спецификация по федеративной модели не соберётся никогда: для Revit это разные параметры с похожими названиями.

Лечится один раз: общий файл параметров, один на компанию, лежит в сетевой папке и подключён во всех шаблонах. Дальше правило простое — новый параметр заводит только BIM-менеджер, а не тот, кому он понадобился в пятницу вечером.

Скучно, зато потом спецификации собираются сами.
